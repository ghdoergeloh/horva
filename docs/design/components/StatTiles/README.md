# StatTiles

Kennzahlen-Kacheln über den Diagrammen der Auswertung: Gesamt, Ø pro Arbeitstag, größtes Projekt, ohne Aufgabe.

- Wert in Geist Mono 28 px (`timer`-Stil, ohne Orange), Einheit klein in `muted-foreground`, eine Zeile Kontext darunter (Soll, Anzahl Tage).
- Keine Farben für gut/schlecht; Abweichungen als Zahl mit Vorzeichen.
- Raster `auto-fit, minmax(150px, 1fr)`: bei 400 px zwei Spalten.
