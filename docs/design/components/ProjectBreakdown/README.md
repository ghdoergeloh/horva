# ProjectBreakdown

Details je Projekt: aufklappbare Zeilen mit Projektpunkt, Name, Anteilsbalken und Summe; aufgeklappt die Aufgaben mit ihrer Zeit.

- Kopfzeile ist ein Knopf (`aria-expanded`); Enter/Leertaste klappt, Pfeiltasten wechseln die Zeile.
- Anteilsbalken relativ zum größten Projekt, in Projektfarbe auf `muted`. Bei 400 px entfällt der Balken.
- Lange Aufgabentitel brechen um. Zeiten rechtsbündig in Geist Mono.
- Der Knopf „An Moco übertragen“ sitzt im Kopf des Abschnitts.
